## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Dev Server
```bash
npm run dev
```
Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.

### 3. Build for Production
```bash
npm run build
```

## 🌟 Key Features
- **🌐 National Command Gateway**: Interactive state & UT directory with real-time multi-criteria search and national threat alerts.
- **🏛️ State Disaster Management Portal**: Official Assam State / Guwahati District portal with official government emblems.
- **🗺️ Tactical OpenStreetMap (Leaflet)**: Real-time geospatial map with pulsating radar beacons, urgency ranking, and relief demand checklist.
- **🌊 Hydrodynamic Simulation Bento**: Predictive flood modeling across T-0 to T+72 hours with dynamic demographic and infrastructure risk calculations.
- **📊 Resource Allocation Decision Support (RADS)**: Algorithmic comparison of Manual vs. AI-Optimized supply dispatch routing.
- **🎬 GSAP Animations**: Smooth, physics-based UI transitions, spring-bounce card reveals, and staggered marker cascades.
